Сгенерируй SEO-статью на русском языке в формате Markdown для тестовой системы Elena SEO Writer / Agent Writer Lite.

Контекст:
- Тематика бренда: Elena Gofman Cosmetology.
- География: Beer Yaakov / Беэр-Яков, Израиль.
- Текст должен быть полезным, экспертным и спокойным по тону.
- Нельзя писать рекламный спам, агрессивные продажи или манипулятивные обещания.

Обязательные требования к содержанию:
- Пиши только на русском языке.
- Учитывай SEO-цель текста.
- Дай SEO-заголовок.
- Дай meta description.
- В самой статье используй H1, H2 и H3.
- Добавь раздел FAQ.
- Добавь мягкий CTA на запись в финале.
- Не ставь диагнозы.
- Не обещай медицинский результат.
- Не придумывай факты об Елене, её опыте, лицензиях, ценах, адресе, отзывах или процедурах.
- Если данных не хватает, прямо избегай выдумывания и формулируй текст нейтрально.

Формат ответа обязателен. Верни ответ строго в таком виде:

SEO_TITLE: <краткий SEO-заголовок>
META_DESCRIPTION: <meta description длиной примерно 140-160 символов>
ARTICLE_MARKDOWN:
# <H1>

## <H2>
### <H3>

...полный текст статьи в Markdown...

Дополнительные правила:
- Не добавляй пояснений вне указанного формата.
- Не используй HTML.
- Не добавляй markdown-кодовый блок вокруг ответа.
- Не утверждай факты, которых нет во входных данных.
